# 🛢️ Visor Interactivo de Áreas Hidrocarburíferas

Herramienta desarrollada en Python y Streamlit para la visualización y análisis de áreas concesionadas de Oil & Gas en Argentina. 

## 🚀 Características
- **Visualización dinámica:** Mapeo de polígonos sobre cartografía de alta definición (Esri).
- **Filtro interactivo:** Resaltado visual instantáneo según la empresa operadora de los yacimientos.
- **Geocodificación inversa:** Búsqueda mediante extracción de coordenadas (o URLs de Google Maps) para determinar en qué área o concesión específica recae un punto de interés.
